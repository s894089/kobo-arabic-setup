# docs/

`guide.html` — a bilingual (Arabic / English) manual for this setup.

Open it in any browser:

    open docs/guide.html          # macOS
    xdg-open docs/guide.html      # Linux
    start docs\guide.html         # Windows

It is a single self-contained file. Eight sections cover what a Kobo, Nickel,
NickelMenu and KOReader each are; the prerequisites and ground rules; what this
repository contains; how to install; exactly which settings and plugins change;
how to use KOReader day to day; how to organise a library with folders and
collections; and how to keep it all working.

Use the عربي / English / Both switch at the top right.
