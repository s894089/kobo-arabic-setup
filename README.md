# إعداد كوبو للقراءة العربية

<div dir="rtl">

إعداد جاهز لقراءة العربية على أجهزة **Kobo**: قارئ **KOReader** مع خطوط نسخ
عربية، وقاموسَي عربي‑إنجليزي وإنجليزي‑عربي، ومجموعة إضافات مختارة — بأمر واحد.

**كتبك ومواضع قراءتك وتظليلاتك وإحصاءاتك لا تُمَسّ.**

📖 **[الدليل الكامل — عربي وإنجليزي](docs/guide.html)** — ما هو Kobo وNickelMenu
وKOReader، والتهيئة على كل نظام، وما الذي يتغيّر بالضبط، وكيف ترتّب مكتبتك.
افتحه في المتصفّح بعد الاستنساخ.

</div>

---

## ما الذي يُثبَّت

<div dir="rtl">

| | |
|---|---|
| **KOReader** | الإصدار v2026.07.1 — أقوى بكثير من قارئ Kobo، خصوصًا مع ملفات PDF |
| **Amiri** | خط نسخ كلاسيكي، ومعه **AmiriQuran** المضبوط للتشكيل الكامل |
| **عربي ← إنجليزي** | ‏٢٦٬٥٧٨ كلمة، مع فهرس تصريفات (فتُعرَف «والكتاب» على أنها «كتاب») |
| **إنجليزي ← عربي** | ‏٨٧٬٤٢٣ كلمة |
| **Project: Title** | واجهة مكتبة أوضح وأسرع تصفّحًا |
| **App Store** | تصفّح إضافات KOReader وثبّتها وحدّثها من الجهاز نفسه |
| **LocalSend** | نقل ملفات لاسلكي، بلا كابل ولا خادم |
| **خط الواجهة** | يمكن تغيير خط القوائم والمتصفّح إلى Amiri، فتُقرأ الواجهة نفسها بعربية صحيحة |
| **Simple UI** | شاشة رئيسية بديلة — ساعة، اقتباس اليوم، أغلفة، إحصاءات قراءة، إجراءات سريعة |
| **Bookshelf** | متصفّح ملفات بشكل رقائق/شبكة/قائمة مع بطاقة تفاصيل الكتاب (يحتاج تفعيل CoverBrowser المدمج في KOReader) |
| **Reading Insights** | شاشات إحصاءات — وقت القراءة، التتابعات اليومية، رسوم شهرية، سجلّات، إنجازات |
| **Bookends** | ترويسة/تذييل داخل الكتاب — أرقام الصفحات، أشرطة التقدّم، أنماط جاهزة |
| **Annotations Viewer** | تصفّح كل تظليل وملاحظة في مكتبتك وتعديلها وإدارتها من مكان واحد |
| **الأيقونات** | مجموعة Hugeicons — تستبدل أيقونات المتصفّح وشريط الأدوات |

كما تُضاف أربعة تعديلات (patches) صغيرة: نمط شاشة توقّف بحالتين، خيار استثناء
كتب معيّنة من شاشة التوقّف بنمط الغلاف، وتنبيه «رجوع إلى آخر موضع توقّفت فيه
فعليًا» بعد التنقّل داخل الكتاب، وتعديل يخفي مجلدات كوبو غير الكتبية في الجذر
(`fonts/` و`Exported Annotations/` و`Exported Notebooks/` و`My Notebooks/`)
من متصفّح الملفات — لا يُحذف شيء، فقط لا تُعرض.

### تحصل على الإعداد كاملًا، لا الإضافات وحدها

المثبّت ينقل **الإعدادات نفسها** لا البرمجيات فقط: شاشة Simple UI الرئيسية
وصفحاتها، وشريط التنقّل، وقوالب Bookshelf ورقائقه، ونمط Bookends، والإيماءات،
ومجموعة الأيقونات. استنسخ، شغّل، أعد التشغيل — فيصير جهازك كالجهاز الذي بُني
منه هذا المستودع.

**أمّا قراءتك فتبقى لك وحدك.** الإحصاءات والتتابعات والسجلّ والمفردات
والتظليلات والملاحظات وكل مجلدات `.sdr` مستثناة من النسخ ومن الحذف معًا. هذا
المثبّت يمنحك **تصميم** غيرك، لا بيانات قراءته — ولا يمسّ بياناتك أنت.

ويُضبط كذلك: العربية لغةً لنصّ الكتاب — فيصحّ ضبط الأسطر وفصل المقاطع.
أمّا **واجهة البرنامج فتبقى بالإنجليزية**؛ المتغيّر هو طريقة عرض النص لا القوائم.

## المتطلّبات

<div dir="rtl">

1. **جهاز Kobo عليه [NickelMenu](https://pgaskin.net/NickelMenu/) مسبقًا.**
   هذه الحزمة تُثبّت KOReader ولا تُثبّت NickelMenu. وبما أن NickelMenu هو
   الطريق الوحيد لتشغيل KOReader، فبدونه ستكون ثبّتّ قارئًا لا تستطيع فتحه.
2. **صدفة فيها `rsync` و`git` و`python3`** — انظر نظامك أدناه.
3. **‏٢٠٠ ميغابايت فارغة** على الجهاز.
4. الجهاز **موصول ومفتوح القفل، وضغطت فيه Connect**.

### macOS

كل شيء موجود أصلًا — `rsync` و`git` و`python3` تأتي مع النظام (قد يُطلب منك
تثبيت Xcode command line tools أول مرة).

يظهر الجهاز في `/Volumes/KOBOeReader` ويُكتشَف تلقائيًا.

### Linux

</div>

```bash
sudo apt install git rsync python3          # Debian / Ubuntu
sudo dnf install git rsync python3          # Fedora
```

<div dir="rtl">

يظهر الجهاز عادةً في `/media/$USER/KOBOeReader` أو `/run/media/$USER/KOBOeReader`،
وكلاهما يُكتشَف تلقائيًا.

### Windows

السكربتات مكتوبة بـ bash، فتحتاج إحدى طريقتين:

**الأولى — WSL (المستحسنة).** في PowerShell كمسؤول:

</div>

```powershell
wsl --install
```

<div dir="rtl">

أعد التشغيل، افتح **Ubuntu** من قائمة ابدأ، ثم:

</div>

```bash
sudo apt update && sudo apt install git rsync python3
```

<div dir="rtl">

يظهر الجهاز في WSL كحرف قرص تحت `/mnt` — فإن كان القرص `E:` صار `/mnt/e`،
وتجده السكربتات تلقائيًا.

**الثانية — Git Bash.** يعطيك صدفة bash، لكنه **لا يتضمّن `rsync`** وهو أساس
هذه السكربتات، فتضطر لإضافته يدويًا. لذا WSL أبسط بكثير.

وإن لم يُعثر على جهازك، أشِر إليه مباشرة:

</div>

```bash
KOBO_MOUNT=/mnt/e ./install.sh
```

## التثبيت

<div dir="rtl">

ثلاث خطوات. استنسخ في أي مجلد تريد — لا حاجة لمسار معيّن.

**١.** وصّل جهاز Kobo، افتح قفله، واضغط **Connect** على شاشته.

**٢.** استنسخ وادخل المجلد:

</div>

```bash
git clone https://github.com/s894089/kobo-arabic-setup.git
cd kobo-arabic-setup
```

<div dir="rtl">

**٣.** شغّل:

</div>

```bash
./install.sh
```

<div dir="rtl">

هذا كل شيء. يأخذ نسخة احتياطية أولًا، يعرض ما سيفعله، ثم يسألك `y` للمتابعة.
وإن لم يجد جهاز Kobo فسيتوقّف دون أن يغيّر شيئًا.

ثم: أخرِج القرص ← **NickelMenu ← Reboot** ← **NickelMenu ← KOReader+**

أول تشغيل بطيء لأنه يبني ذاكرة الأغلفة. هذا طبيعي.

للمعاينة قبل التنفيذ:

</div>

```bash
./install.sh --dry-run
```

## كيف تستعمله — Bookshelf و Simple UI

<div dir="rtl">

يفتح الجهاز على لوحة **Simple UI**. و**Bookshelf** هي مكتبتك، على بعد نقرة
واحدة من زرّ **Library**. وتنتقل بينهما من الشريط السفلي.

### الشريط السفلي

</div>

| الزر | ما يفتحه |
|---|---|
| **Library** | Bookshelf — كتبك |
| **Settings** | إعدادات Simple UI |
| **Home** | لوحة Simple UI |
| **Insights** | وقت القراءة والتتابعات والرسوم الشهرية |
| **History** | آخر ما فتحته |
| **Power** | نوم، إعادة تشغيل، إطفاء |

<div dir="rtl">

### Bookshelf — المكتبة

- **الرقائق في الأعلى** تُرشِّح الرفّ: الرئيسية، المؤلفون، السلاسل، وما تضيفه أنت.
  **اضغط مطوّلًا على رقاقة** لتغيير مصدرها وشكل عرضها.
- **اسحب لأعلى من منطقة الأغلفة** للتبديل بين شبكة الأغلفة وقائمة نصّية،
  واسحب لأسفل للعودة.
- **اضغط مطوّلًا على كتاب** لبطاقة تفاصيله: الوصف والسلسلة والتقدّم.
- التشغيل الأول بطيء: يبني صورة مصغّرة لكل كتاب مرّة واحدة، ثم يصير سريعًا.

### Simple UI — لوحة المعلومات

اضغط **Home**، ثم اسحب يمينًا ويسارًا بين الصفحات، والنقاط تدلّك على موضعك.

- **الصفحة ١** — الساعة، وما تقرأه الآن، وإحصاء اليوم
- **الصفحة ٢** — أحدث الكتب، وأهداف القراءة (السنة / الشهر / اليوم)، وقائمة
  «سأقرؤه لاحقًا»

ولإعادة ترتيب ذلك كلّه: **Settings ← Home Screen ← Edit Home Screen Layout**؛
تضيف صفحات وتحذفها، وتنقل الوحدات بينها، وتغيّر أحجامها.

وأهداف القراءة في: **Settings ← Home Screen ← Reading Goals**، تضبط فيها
هدف السنة والشهر واليوم.

### داخل الكتاب

- **Bookends** يرسم الترويسة والتذييل: أرقام الصفحات وأشرطة التقدّم.
  تغيّره من **📄 ← Bookends ← Preset**.
- **Annotations Viewer** يجمع كل تظليلاتك وملاحظاتك من كل الكتب في مكان واحد.
- **انقر أعلى الصفحة** للقوائم، و**أسفلها** لشريط التقدّم.

### لجعل الواجهة عربية

القوائم تأتي بالإنجليزية. ولتغيير خط الواجهة إلى Amiri فتُقرأ العربية في
القوائم والمتصفّح قراءةً صحيحة:

**متصفّح الملفات ← ⚙ ← Settings ← UI font ← Amiri**

سيطلب إعادة التشغيل. وهذا الخيار موجود بفضل تعديل `2--ui-font.lua` المرفق؛
فبدونه لا يملك KOReader خيارًا لخط الواجهة أصلًا.

</div>

## إضافة الكتب

<div dir="rtl">

يُنشئ المثبّت على جهازك مجموعة مجلدات موضوعية للبداية — بالشكل نفسه الذي
يستعمله هذا الإعداد — وهي مذكورة في `library/FOLDERS.txt`. ولا يُنشئ إلا ما
ليس عندك: فالمجلدات الموجودة لا يُعاد تسميتها ولا تُفرَّغ، ولا تُمَسّ الكتب
التي بداخلها. وعدّل ذلك الملف لتضع أسماء مجلداتك أنت.

مجلد `library/` يأتي فارغًا، فالاستنساخ لا يمسّ كتبك. ضع مجلدات كتبك بداخله —
مجلدًا لكل موضوع — ثم شغّل `./install.sh` مرّة أخرى.

</div>

```
kobo-arabic-setup/library/
    تاريخ/
        اسم الكتاب - المؤلف.epub
    روايات/
        اسم الكتاب - المؤلف.epub
```

<div dir="rtl">

نسخ الكتب **يضيف فقط**: لا يحذف شيئًا موجودًا على الجهاز، ولا يلمس مجلدات
`.sdr` التي تحمل التظليلات والملاحظات ومواضع القراءة.

</div>

إن لم يُعثر على جهازك:

</div>

```bash
KOBO_MOUNT=/mnt/e ./install.sh
```

## ما يُستبدل وما يبقى

<div dir="rtl">

**يُستبدل** — `.adds/koreader/` و`.adds/nm/menu` و`.kobo/dict/` و`fonts/` و`wallpapers/` (الخطوط والخلفيات تُضاف فقط ولا يُحذف منها شيء)

**يبقى دائمًا** — كتبك · كل مجلدات `.sdr` (مواضع القراءة والتظليلات) ·
`statistics.sqlite3` · `history.lua` · مفردات vocabulary builder · إعدادات KoInsight

يستعمل المثبّت `rsync --delete` حتى تُزال فعلًا الإضافات التي أسقطتها هذه الحزمة
بدل أن تبقى معلّقة — لكن كل ملف شخصي مذكور أعلاه مستثنى من النسخ ومن الحذف معًا.

</div>

## ملاحظة مهمّة على مجلدات `.sdr`

<div dir="rtl">

يحفظ KOReader موضع قراءتك وتظليلاتك وإعدادات كل كتاب في مجلد `.sdr` **بجانب
الكتاب، والربط بينهما بالاسم**. فإن غيّرت اسم كتاب أو نقلته، غيّر اسم مجلده
بالطريقة نفسها في الوقت نفسه، وإلا فقدت تظليلاته.

هذا المثبّت لا يلمس هذه المجلدات إطلاقًا.

</div>
